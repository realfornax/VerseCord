# VerseCord

VerseCord is a self-hosted chat service with servers, voice and video calls, and end-to-end encrypted direct messages.

VerseCord serves a customized web client powered by Equicord. Sign in with a VerseCord account; no Discord account is required.

**VerseCord is in early alpha.**

## Self-host VerseCord

You need a Linux host with Docker, a domain pointing at it and a public IPv4 address for voice. The [setup guide](docs/self-hosting/setup.md) installs it with Docker Compose, and the [native Linux guide](docs/self-hosting/native.md) runs it under systemd instead. See [the documentation index](docs/README.md) for more.
